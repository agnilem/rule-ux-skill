# Credits

Rule UX is an original skill written for Rule. It has no opinion on visual style by design. Its content is a rewritten and condensed synthesis of ideas from the sources below; no visual or brand guidance from them is included.

- **Impeccable** by Paul Bakaus, Apache License 2.0. https://github.com/pbakaus/impeccable
  Ideas from the `onboard`, `harden`, `clarify` and `distill` commands (empty states, first run, error and edge cases, interface copy, simplification). Changes: rewritten in our own words, shortened, all visual, typographic, color and motion guidance removed, made stack-neutral.
- **Web Interface Guidelines** by Vercel, MIT License, Copyright (c) Vercel, Inc. https://github.com/vercel-labs/web-interface-guidelines
  Rules on forms, focus, accessibility, navigation and state, and copy. Changes: rewritten as stack-neutral statements, React and Next.js specifics, performance, theming and mobile safe-area rules removed.
- **ux-heuristics** by wondelai, MIT License. https://github.com/wondelai/skills
  The structure of heuristic review with a severity scale.
- **10 Usability Heuristics** by Jakob Nielsen, Nielsen Norman Group. https://www.nngroup.com/articles/ten-usability-heuristics/
- **Don't Make Me Think** by Steve Krug.
- **Laws of UX** by Jon Yablonski. https://lawsofux.com/
