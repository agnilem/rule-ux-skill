# Words in the interface

Check every string on the screen. In Rule, texts live in the translations file; propose changes as before and after pairs.

## By function

- **Buttons and menu items:** a verb plus the object, saying exactly what happens. "Send to 12,480 subscribers", "Delete segment". Not "OK", "Yes", "Continue", "Submit".
- **Titles:** name the thing or the task. A modal title and its main button use the same verb.
- **Labels:** the user's word for the thing, a noun, no colon games, no questions unless it is a yes or no choice.
- **Help text:** only what is not obvious from the label, in one sentence, placed where the question arises. If it restates the label, delete it.
- **Confirmations:** say what will happen and to what, with the name or count, and whether it can be undone. The buttons repeat the action: "Delete campaign" and "Cancel", never "Yes" and "No".
- **Errors:** what happened, why if known, what to do now. No blame, no codes as the main message, no "Oops".
- **Empty states:** what will appear here and the one action to start.
- **Loading and progress:** say what is happening if it takes more than a moment: "Importing 2,400 subscribers".
- **Success:** state the result, briefly. Do not celebrate routine actions.

## Rules

- One term per thing across the whole product. If the product says "subscriber", never "contact" or "recipient" for the same thing.
- Use the product's existing terms and casing; do not introduce a new style.
- Active voice, second person, present tense.
- Numerals for numbers. Real numbers and names instead of "items" or "this".
- Cut filler: "please", "simply", "just", "in order to", "successfully".
- No jargon, no internal names, no abbreviations the user did not choose.
- The same sentence must work when translated: no word order tricks, no text split across elements, room for longer languages.
- Options in a choice are parallel: same grammar, comparable length, mutually exclusive.

## Test

Read only the title and the main button. Is it clear what happens when it is pressed? If not, that is a level 3 finding.
