# Rule UX

A Claude skill that reviews how a Rule screen works for a person: clarity, states, forms, words. It has no opinion on visual style.

## Install

Paste into Claude Code:

    Выполни: git clone https://github.com/agnilem/rule-ux-skill ~/.claude/skills/rule-ux

## Use

In a new chat, in plain words:

- "Проверь UX этой модалки"
- "Каких состояний не хватает на этом экране?"
- "Проверь тексты в этой форме"

Works best next to the `rule-prototypes` skill: fixes then name the exact Rule component.
